# Operation: Grandfather - Interactive Dossier

**A Digital Preservation of a WWII Journey (1943-1946)**

This project is an interactive web application designed to visualize and preserve the personal history of a World War II soldier. By combining transcribed journal entries, historical context, and an interactive map, it brings a grandfather's service record to life for future generations.

## 🗺️ Project Overview

"Operation: Grandfather" transforms a collection of handwritten journal pages and oral history into an immersive digital experience. Users can follow the soldier's path from induction in Los Angeles, through training in the US, the Atlantic crossing, the advance through Europe, and the final return home.

## ✨ Key Features

*   **Interactive Map**: A dynamic Leaflet.js map tracking the 135th Evacuation Hospital's movement across the US and Europe.
*   **Mission Log**: A step-by-step narrative of 16 distinct "missions," from Basic Training to the Occupation of Germany.
*   **Field Archives**: A digital library of the original handwritten journal pages, fully synchronized with the story.
*   **Service Record**: A gamified achievement system tracking medals and badges earned throughout the journey.
*   **Secret Intel**: Hidden historical context and "declassified" stories revealed through interaction.

## 📂 Project Structure

*   `Map.html`: The main application file containing all HTML, CSS, and JavaScript.
*   `imgs/`: Directory containing digitized journal pages and historical photos.
*   `Grandfather's WWII Story_Corrected.md`: The complete, corrected text transcription of the journal.
